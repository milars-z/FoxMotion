# 保密上传

在 Studio 的「生成设置」打开「保密上传」。开关在切换文生、首尾帧和参考生成时保持选择。提交成功会清空表单中的提示词、文件和浏览器预览。历史列表以「保密任务」显示。完成后可以播放、下载；确认下载到本机后，在任务详情点击「清理保密任务」并确认。下载和 HTTP Range 请求本身不会触发删除。正在生成的任务应先取消，等待结束后再清理。

## 路径和保留期

| 内容 | 当前 Pod 容器本地路径 | 清理时机 |
|---|---|---|
| multipart 临时文件及提交暂存 | `/opt/video-runtime/data-private/spool/<上传UUID>/` | 请求结束；进程异常退出后由 Worker 识别失效的上传锁 |
| 原始上传、提示词与文件角色 | `/opt/video-runtime/data-private/jobs/<任务UUID>/inputs/`、`request.json` | 任务结束或取消 |
| 执行和恢复清单 | 同一任务目录中的 `stage.json`、`comfy.json` | 本机队列、缓存和定向历史清理确认后 |
| 推理输入、标准化视频或音频、caption | `/opt/video-runtime/comfy/input/foxmotion-private/<随机执行UUID>/` | 任务结束且 Comfy 清理确认后 |
| Comfy 原始输出 | `/opt/video-runtime/comfy/output/foxmotion-private/<随机执行UUID>/` | 同上 |
| 临时播放与下载成片 | `/opt/video-runtime/data-private/jobs/<任务UUID>/result/<随机名>.mp4` | 用户确认或到期 |
| Studio 调度记录 | `/opt/video-runtime/data/studio.db` | 确认清理或到期时删除整行 |

Studio 的保密调度行只含执行所需的编号、模式、状态、时间和采样配置。提示词列为空、素材清单为 `[]`。普通快照在本地 SQLite 副本上排除全部保密行并执行 VACUUM，随后才写入 Global Volume。恢复后的普通任务保留原有素材和成片规则。运行环境归档仍仅包含两个虚拟环境、Node、GPU 约束与前端构建。保密路径拒绝符号链接越界和 Global Volume 使用的 FUSE 文件系统。

`PRIVATE_RETENTION_SECONDS` 默认为 3600 秒，允许 60 至 604800 秒。按任务结束时间计算。结果接口到期即拒读，Worker 每约 10 秒检查到期任务，即使另一条长任务正在运行。Worker 每约 60 秒检查上传残留。设置方式为 API 与 Worker 的共同环境变量；当前 Supervisor 若未继承此变量，两服务也会读取其工作目录 `/opt/video-runtime/.env` 中的该项。改值在这两个进程下一次启动时生效。迁移后的启动配置可在 `deploy/runpod/.env` 设置。无需为此重启 ComfyUI。

## 推理缓存和故障处理

固定版 ComfyUI 的 classic 输出缓存会保留参考张量和条件编码，对象缓存会保留节点实例。仅删除成片或清理原生历史都不足以释放这些引用。保密图使用原生 caption 加载节点，从匿名目录内的 UTF-8 文件读取正文；传送的图中只有本地路径。输入图重新编码为无原始元数据的 PNG，参考音视频标准化；下载成片重新封装并移除容器元数据与章节。私密模式限制节点类型、媒体文件路径和唯一成片输出，要求 classic 缓存且关闭资产索引。

私密生成取得终态后，Worker 提交一个仅输出常量的维护图。被执行的输出分支没有采样或解码节点。图中保留同一组模型、编码器、VAE 与模型补丁节点及其原输入签名，供固定版执行器 `set_prompt` 和 `clean_unused` 复用缓存。随后通过原生 `POST /history` 按 ID 清理本次生成与维护记录，并核验结果。不调用 `/free`。普通任务历史与其他输出不在删除范围内。

Worker 在提交前记录随机 Comfy ID 和维护图。失败、取消、连接中断或 Worker 重启后，使用同一份清单重试清理，不会重投视频生成。状态不确定或 Comfy 队列非空时，保留清单并等待。界面会显示清理待完成。若服务停止，磁盘清理须等服务恢复；已到期的成片在 API 可用时拒绝新的读取请求。应用会返回清理冲突，直至可安全删除。

## 验证与边界

- 合成图像、视频、声音经过隔离 Mock API、Worker 和浏览器。验证了上传、预览清空、历史重载、实际播放、下载、206 分段读取、确认清理及后续 404。
- 测试覆盖超阈值 multipart 在请求目录内溢写、快照原始字节无测试提示词与任务编号、运行时归档排除、已取消和失败任务、Worker 中断、失联重试、超时删除及普通任务保留。
- 固定 commit 的独立 CPU Comfy 进程验证了 8 套保密 H3 图及 8 套维护图。真实 classic 执行器清除了测试 caption 节点和实际张量的引用，保留了测试模型加载节点的同一个缓存对象。Comfy 的真实 H3 GPU 保密生成留给网页手动验收。
- 本功能面向独占 Pod 的本地用户。执行中，宿主机、同权限进程及可访问回环端口的客户端仍可能看到临时文件、队列或内存；异常历史在定向清理完成前可能含节点输入。诊断中可能留下运行时间、错误类型、随机路径或编号。客户端已下载的文件、浏览器/系统缓存、运维层快照和设备残留超出应用清理范围。
- 删除目录、SQLite 行和缓存引用属于逻辑清理。文件系统页、写前日志、存储块及 GPU/CPU 分配器未执行可验证的物理覆写。运行环境无法提供物理介质安全擦除保证。
